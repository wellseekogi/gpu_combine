# 개인 GPU 제공과 토큰 이용

GPU 제공자와 GPU 이용자는 같은 개인 계정을 사용합니다. 여러 PC에서 얻은 기여 수익이 하나의 잔액에 쌓이고, 그 잔액으로 다른 사람의 GPU를 이용합니다. 운영자가 GPU 등록이나 작업 실행을 일일이 승인하지 않습니다.

| 구분 | 역할 |
|---|---|
| 개인 계정 | 내 GPU 등록·제공 제어, 내 잔액·수익 조회, 내 토큰으로 다른 GPU 작업 요청 |
| PC 연결 키 | 특정 PC가 자기 모델 계약으로 작업을 받아 실행·제출 |
| 스케줄링 서버 | 가용 GPU 매칭, 잔액 예약, 실행 권한 관리, 결과 확정과 정산 |
| 운영자 | 서비스·보안 관리, 문제 노드 차단, 원장 점검과 추가 토큰 배정 |

서비스 토큰은 정수 크레딧 **CR**입니다. 로그인 비밀키나 LLM 입출력 토큰 개수와는 다릅니다. 현재 지원하는 유료 작업은 **문서별 정보 추출**이며 문서 1개에 10 CR, 결과 확정 시 제공자 9 CR·서비스 1 CR을 정산합니다. 초당 GPU 임대나 분산 LLM 경로의 자동 과금은 아직 연결하지 않았습니다.

## 개인 계정과 기본 토큰

1. 웹의 **내 GPU·토큰** 또는 **내 GPU 연결하기**를 엽니다.
2. 표시 이름으로 개인 계정을 만듭니다. 기본 설정은 가입 시 **100 CR 자동 지급**입니다.
3. **계정 복구 파일 저장**을 누릅니다. GPU 등록 전에 필요한 단계이며, 다시 로그인하거나 다른 컴퓨터에서 접속할 때 사용합니다. 등록 폼의 **계정 복구 파일 저장하고 계속** 버튼으로도 저장할 수 있습니다.
4. 사용 가능 토큰, 예약 토큰, 기여 수익과 이용·수익 내역을 확인합니다.

서버 환경변수 **RELAY_SIGNUP_CREDITS**는 가입 토큰 수로 기본 100, 허용 범위는 0~1000입니다. 동일 계정의 가입 요청 재시도·동시 요청·서버 재시작으로 재지급하지 않습니다. 회원 등록과 잔액 발행은 하나의 SQLite 트랜잭션에 저장하며 클라이언트가 지급량을 정할 수 없습니다.

계정은 복구 파일 기반의 개인 자격증명입니다. 이메일·실명 인증은 없으므로 서로 다른 새 계정이 실제 같은 사람인지 판별하지는 않습니다. 가입 호출 제한과 서버당 256개 계정 상한을 적용합니다. 비밀키는 브라우저 영구 저장소에 기록하지 않고 서버에는 해시만 저장합니다.

## 내 GPU 제공

1. **내 GPU 제공**에서 PC 설정 도우미를 내려받고 압축을 풉니다. 참여자 PC에서 **START-PROVIDER.cmd**를 실행합니다. 참여자 PC에 스케줄링 서버를 새로 실행할 필요는 없습니다.
2. 웹의 **내 GPU 제공**에서 **연결 코드 만들기**를 누릅니다. 코드는 10분 동안 유효하며 한 PC만 등록할 수 있습니다.
3. 도우미에서 **GPU만 제공**과 llama-server를 선택한 뒤 **서버에 바로 연결**을 누릅니다. 도우미가 실행 환경을 검사하고, 연결 코드·PC 이름·GPU 메모리를 받아 서버에 직접 등록합니다. 확인 JSON을 저장하거나 웹에 첨부할 필요가 없습니다.
4. 도우미가 PC 연결 정보를 보관합니다. 웹에서 해당 GPU가 등록된 것을 확인한 뒤 도우미의 **검사하고 참여 시작**을 누릅니다. 실제 heartbeat가 와야 제공 중으로 표시됩니다. 운영자 승인 대기는 없습니다.
5. 웹의 **제공 일시 중지**는 새 배정을 중지하고 현재 실행 권한을 회수합니다. PC 프로그램은 해당 상태를 확인해 실행기를 중지합니다. **제공 허용**은 배정을 다시 허용하며 종료된 PC 프로그램을 실행하지는 않습니다.
6. PC에서 제공 프로그램까지 끝내려면 **참여 중지**를 누릅니다.

계정 복구 파일은 다시 로그인할 때 계속 필요합니다. PC 연결 정보는 도우미가 해당 PC에 자동 보관하며 그 PC의 실행에만 사용합니다. 이전 도우미의 JSON 파일 연결도 호환용으로 유지합니다. PC를 추가해도 가입 토큰을 다시 지급하지 않습니다. 자기 계정이 소유한 GPU를 구매 대상으로 지정할 수 없습니다.

GPU 메모리는 그 PC의 제공 정보입니다. 처음 등록한 고용량 GPU의 메모리를 같은 모델을 쓰는 모든 PC의 최소 요구량으로 강제하지 않습니다. 등록만으로 모델이 실제 GPU에서 실행된다는 것을 보증하지 않으며 PC 실행 단계에서 확인합니다.

## 다른 GPU 이용과 정산

**다른 GPU 사용**에서 제공 중인 다른 사람의 GPU를 선택하고 공개 문서와 찾을 항목을 입력합니다. 서버는 인증된 계정을 결제 계정으로 사용하며 브라우저가 보낸 다른 사람의 결제 계정 ID를 신뢰하지 않습니다.

요청 시 잔액에서 비용을 예약합니다. 동시에 요청해도 잔액을 중복 사용할 수 없습니다. 결과가 확정되면 예약 비용을 정산하고 제공자의 개인 잔액에 수익을 더합니다. 취소·실패로 사용하지 않은 예약은 해제합니다. **이용·수익 내역**에서 결과와 거래 기록을 확인합니다.

개인 조회에는 자기 잔액·작업·문서·거래만 반환합니다. 다른 GPU의 공개 제공 정보는 볼 수 있지만 다른 사람의 잔액·문서·작업은 조회하거나 변경할 수 없습니다.

## 운영과 호환성

운영자 콘솔은 운영·보안 점검에 유지합니다. 크레딧 원장에서 개인 계정에 추가 토큰을 배정할 수 있으며 이는 기존 운영 준비금에서 이전합니다. 가입 기본 지급과 달리 추가 배정은 새 토큰을 발행하지 않습니다.

이전의 승인 대기 신청 경로는 더 이상 사용하지 않습니다. 개인 계정을 만들고 GPU를 직접 등록합니다. 이전에 발급한 정상 PC 연결 파일의 인증과 제공자 프로토콜은 유지하지만, 기존 운영자 등록 노드를 개인 계정으로 자동 이전하지는 않습니다.

현재 한 서버의 파일럿 규모는 모델 계약 8개·노드 20개입니다. 이 문서의 개인 토큰 흐름은 문서별 독립 추론 경로에 해당합니다.
